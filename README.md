# bench

A portrait of your Claude Code practice.

One page. Scan your `.claude/` setup → receive a shareable bench card: hours Claude gave back, your signature verbs, your missing moves.

Zero revenue. Adoption-first. Score-only.

## Run locally

```
python3 -m http.server 5173
```

Then open http://localhost:5173

## Stack

Static HTML + CSS + JS. No build step. Synthetic persona data (Sam · Priya · Maya · Alex) until the scan engine lands.
